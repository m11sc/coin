# Крипто-сигналы в Telegram + Mini App со статистикой

Бот на Python ищет точки входа по криптовалютам, присылает сигналы в Telegram и сам следит за сделками до выхода.
Статистика по всем сделкам открывается прямо в Telegram — кнопкой «📊 Статистика» в меню бота.

Работает полностью бесплатно: без сервера, на GitHub Actions и GitHub Pages.

## Что умеет

- **Сигналы.** Лонг и шорт по стратегии EMA 9/21 + RSI с фильтром тренда EMA 200, стоп и цель по ATR (риск/прибыль 1:2).
- **Сопровождение сделки.** Сообщает о выходе: стоп, цель или разворот. Считает результат с плечом и комиссиями, цену ликвидации, размер маржи.
- **Все монеты.** Режим `SYMBOLS=ALL` — все пары к доллару с оборотом выше заданного.
- **Статистика (Telegram Mini App).** Процент прибыльных сделок, средний и суммарный результат, график накопленного результата, итоги по монетам, открытые сделки с текущей ценой и положением между стопом и целью.
- **Бэктест.** Та же стратегия на истории за последние недели — чтобы оценить её до реальных сделок.

## Как устроено

```
GitHub Actions (каждые 5 минут)
  └─ crypto_signals.py ── свечи с биржи (Coinbase / Binance)
        ├─ сигнал / выход ──────────────► сообщение в Telegram
        └─ сделка открылась или закрылась ► docs/data/trades.json (коммит в репозиторий)

GitHub Pages (папка docs/)
  └─ index.html — Mini App, читает trades.json и backtest.json

Кнопка меню бота (setChatMenuButton) ──► открывает Mini App внутри Telegram
```

Бэктест (`backtest.py`) вызывает те же функции входа и выхода, что и бот. Поэтому на одних и тех же свечах он даёт ровно те же сделки, что бот дал бы вживую.

## Стек

Python · requests · Telegram Bot API · Telegram Mini Apps (WebApp) · GitHub Actions · GitHub Pages · HTML/CSS/JS без библиотек

## Запуск

1. **Секреты** (Settings → Secrets and variables → Actions → Secrets): `TG_TOKEN`, `TG_CHAT_ID`.
2. **Переменные** (там же, вкладка Variables, все необязательные): `SYMBOLS` (например `BTC-USD,ETH-USD` или `ALL`), `INTERVAL`, `LEVERAGE`, `DEPOSIT`, `RISK_PCT`, `ALLOW_SHORT`, `MIN_VOLUME_USD`.
3. **GitHub Pages**: Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/docs`.
4. **Кнопка в боте**: Actions → `setup-menu` → Run workflow.
5. **Бэктест** (по желанию): Actions → `backtest` → Run workflow.

Статистика живых сделок начинает собираться с момента запуска. Бэктест заполняет вкладку «История» сразу.
